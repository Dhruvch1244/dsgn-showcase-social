# Thrum — a dsgn showcase (work in progress)

> 🚧 **This build is still in progress.** Pushed early at the user's request
> rather than held back until finished — some views/polish may be
> incomplete, and the full writeup (the exact prompt, the component list,
> local-edit rationale) hasn't been written yet. `tsc --noEmit` and
> `next build` are both clean as of this push. Check back for updates, or
> see [Halyard](https://github.com/Dhruvch1244/dsgn-showcase-analytics) and
> [Alcove](https://github.com/Dhruvch1244/dsgn-showcase-tasks) for the
> finished version of this pattern.

Thrum is a **fictional** social/community feed app, built to prove out
[`@dhruvchoudhary/dsgn`](https://design.dhruvchoudhary.com) — a genuine
external consumer of the published npm package, in the `startup` style
voice. Nothing here is a mockup of a real company; the product name, the
people, the posts, and every line of copy are invented for this demo.

## Run it

```bash
npm install
npm run dev
```
